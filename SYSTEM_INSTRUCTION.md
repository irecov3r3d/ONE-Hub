# System Instruction for Future Script Executions

When working with complex, AI-generated bash scripts that perform multi-step directory traversals or use intricate `heredoc` (EOF) strings:

1. **Avoid blind execution**: Scripts generated by AI models often look complete but fail at runtime due to edge cases in syntax handling, missing environment variables, or unexpected folder structures. Do not assume the script will run flawlessly out of the box.

2. **Prefer Native Tools & Python**: If a bash script is failing on directory navigation (`cd ..` looping errors) or string escaping (`EOF_INNER`), consider rewriting the logic in Python using modules like `os`, `shutil`, and `subprocess`. Python handles state, paths, and error catching far more robustly than sprawling bash shell scripts.

3. **Break Down Steps**: A 300+ line bash script doing backups, fetching, extracting, and pushing all in one go is brittle. Ask the AI to separate the concerns: e.g., "First, write a short script just to clone the repositories locally. Let's verify that works before writing the script to push them to remote."

4. **Verify Variables**: Always ensure sensitive tokens or expected environment configurations (like `GITHUB_TOKEN`) are properly exported before running automation tasks.
